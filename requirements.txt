#
# 說明：
#   - llama-index：核心（VectorStoreIndex / SimpleDirectoryReader / StorageContext...）
#     預設使用內建 SimpleVectorStore，不需 faiss / torch

#   - pymupdf4llm：PDF → Markdown + OCR（自動帶入 pymupdf；OCR 用 MuPDF 內建
#     binding；OCR 需 ./tessdata/ 訓練資料，未隨映像打包時 OCR 自動停用，
#     圖片改由 VLM 處理）
#   - rank-bm25：BM25 詞面檢索底層（純 Python，僅依賴 numpy）。
#     註：不用 llama-index-retrievers-bm25，因其 bm25s 後端依賴 pystemmer，
#         對 Python 3.14/Windows 無預編譯 wheel，會退回編譯 Rust 而失敗。
